# Engenharia Disciplinada de Software — INFNET (26E2_5)

Este repositório contém os Trabalhos Práticos (TPs) desenvolvidos ao longo da disciplina, demonstrando a evolução arquitetural de uma plataforma completa de comércio eletrônico (**Nexus Store**).

---

## 📌 Trabalhos Práticos (TPs)

- [**TP1**](./TP1/): Estruturação inicial, modelagem de domínio e testes unitários.
- [**TP2**](./TP2/): Persistência, validações e desacoplamento em camadas.
- [**TP3**](./TP3/): Separação em microsserviços (Orders e Shipping) com comunicação síncrona REST / OpenFeign.
- [**TP4**](./TP4/): Refatoração para Arquitetura Orientada a Eventos (EDA) com RabbitMQ, Topic Exchanges e DLQ.
- [**TP5 (Atual)**](./TP5/): **Conteinerização com Docker, Orquestração com Kubernetes (K8s), Observabilidade (Prometheus, Grafana, Zipkin) e Pipelines de CI/CD (GitHub Actions).**
